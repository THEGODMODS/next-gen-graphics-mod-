# GODMODS Manager 0.2.0

## Highlights
- Premium GODMODS Manager interface refresh with clearer navigation, stronger typography and responsive layouts.
- App identity and Windows installer product name updated to **GODMODS Manager**.
- Interaction regression coverage for navigation, buttons and Electron IPC contracts.
- Electron responsiveness improvements: DDS processing and Sider log analysis use worker threads; repeated status work is reduced.
- Existing GODMODS user-data location is preserved across the product rename.

## Validation
- TypeScript validation
- Native Node ESM smoke tests
- Unit and department regression tests
- Production build
- Windows NSIS installer build
- SHA-256 checksums generated by the tagged release workflow

## Important limitations
- This is an application release, not a claim that every GODMODS asset or department is fully mapped and verified in-game.
- Exact PES 2017 executable, patch, data pack and Sider compatibility must be tested on the target setup.
- Installation rollback must be checked on a backed-up installation before public release.
- The supplied full GODMODS artwork still needs final integration as the app-wide backdrop and native executable icon.
