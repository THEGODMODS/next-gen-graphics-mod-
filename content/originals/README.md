# Original content production workspace

THEGODMODS original source products are generated reproducibly by the builders in `tools/`. Generated output is written under `content/originals/generated/` and is not treated as installable until its rights, target mapping, compatibility, rollback and in-game validation gates are satisfied.

## Current first-party source libraries

- **GOD TURF:** six original pitch-surface looks and source maps.
- **GOD KITS:** six original fabric families with weave, normal-source and roughness-source maps.
- **GOD FACES:** five neutral skin microdetail profiles and four hair-fibre profiles, generated by `npm run mods:build-faces`.
- Other departments include original visual, stadium presentation, audio and gameplay source work.

GOD FACES does not bundle real-player likenesses, face meshes, player IDs or roster assignments. Its sidecar maps require verified face/hair UV layouts and material channel conventions before any game integration.

Only include assets THEGODMODS owns or has explicit redistribution rights to. Never copy proprietary PES game files, third-party player faces, club/sponsor marks, or copyrighted recordings into this repository without documented permission.

A content pack is not installable until its real payload, manifest, hashes, licence/provenance, PES 2017/Sider compatibility, Windows CI, rollback evidence and real-game validation have passed the Phase 4 release gates.
