# Original content production workspace

Each THEGODMODS original product line has a machine-readable production brief in `src/catalogue/original-content.ts` and a human-readable project brief in `docs/PHASE_5_CONTENT_LIBRARY.md`.

No game assets are stored here yet. Add source assets only when THEGODMODS owns them or has explicit redistribution rights. Never copy proprietary PES game files, third-party player faces, club/sponsor marks, or copyrighted recordings into this repository without documented permission.

A content pack is not installable until its real payload, manifest, hashes, licence/provenance, PES 2017/Sider compatibility, Windows CI, rollback evidence and real-game validation have passed the Phase 4 release gates.
