# GODMODS Audio Routing Gate — PES 2017

GOD ATMOSPHERE now has measured source WAV QA, but it is not an active PES audio replacement. The 25 club identity cues are synthesized creative stingers, not authentic supporter chants or club anthems. Four ambience beds are generic, not club-specific.

Before creating any routing module, record the exact PES 2017 executable/build, patch and Sider version, then inspect the installed audio slot/event map. Do not infer slot numbers or team IDs from club names or from the source profile's reference IDs.

Each proposed route must have:
- Source WAV path and SHA-256.
- Exact target event/slot identifier from the installed patch.
- Exact team/competition identifier when applicable, with evidence of its meaning.
- Measured peak/RMS and commentary mix review.
- Loop boundary check for ambience beds.
- Controlled test log or capture from the target game.
- Confirmation that original audio remains untouched and rollback disables only the GODMODS route.

A source-audio QA pass is not an event-routing pass. Keep all routes disabled until the target IDs and in-game behaviour are verified.
